# Ideas

Only small, additive features are listed here. Refactors and package-wide redesigns are intentionally excluded.

## 1. Any-or-all tag filtering

Let `TagsFilter` choose whether matching any selected tag or every selected tag is required.

## 2. Exact bulk replacement

Add a bulk action that replaces the selected records' tag set exactly, alongside the existing add and remove operations.

## 3. Tag merging

Merge duplicate or renamed tags into a chosen target, reassign existing relationships, and show usage counts before confirmation.
