# Ideas

Only small, additive features are listed here. Refactors and package-wide redesigns are intentionally excluded.

## 1. Encrypted settings

Allow selected definitions to encrypt values at rest and render a masked re-entry field for secrets such as API keys.

## 2. Defaults and reset actions

Let definitions declare explicit defaults and allow users to reset one setting or an entire group to those defaults.

## 3. Change history

Record the actor and changed values for each save, and allow an authorized user to restore a previous value.
