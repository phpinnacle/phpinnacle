# Ideas

Only small, additive features are listed here. Refactors and package-wide redesigns are intentionally excluded.

## 1. PDF output

Generate a downloadable PDF from the immutable rendered HTML snapshot so issued documents keep the same content even after a template changes.

## 2. Version comparison and restore

Show a side-by-side diff between two template versions and restore an older version by creating a new version rather than rewriting history.

## 3. Bulk generation

Generate documents for selected Filament records with one template and queue the work when the selection exceeds a configurable threshold.
