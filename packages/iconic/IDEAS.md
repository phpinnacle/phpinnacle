# Ideas

Only small, additive features are listed here. Refactors and package-wide redesigns are intentionally excluded.

## 1. Configurable icon sets and weights

Expose field methods for selecting registered Blade icon sets and Phosphor weights instead of limiting discovery to the current built-in set.

## 2. Favorites and recent icons

Keep a browser-local list of favorite and recently selected icons so frequently used choices remain immediately available.

## 3. Application icon allow-list

Let an application restrict the picker to an allow-list or exclude specific icons, keeping product iconography consistent without registering a new icon set.
