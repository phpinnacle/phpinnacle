# Ideas

Only small, additive features are listed here. Refactors and package-wide redesigns are intentionally excluded.

## 1. Comment editing

Allow authors to edit their own comments through the existing policy and show an `edited_at` marker in the comment list.

## 2. Contextual replies

Support one level of replies or quoted comments so a response can retain context without introducing an arbitrarily deep discussion tree.

## 3. Comment notifications

Allow users to subscribe to a comment thread and notify them about new comments or direct `@mentions`.
