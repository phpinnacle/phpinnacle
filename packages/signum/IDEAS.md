# Ideas

Only small, additive features are listed here. Refactors and package-wide redesigns are intentionally excluded.

## 1. Per-user acknowledgement

Track read and dismissed state per user so one person's dismissal does not remove a record-level alert for everyone else.

## 2. Scheduled visibility

Add optional `starts_at` and `expires_at` values so temporary alerts appear and disappear without manual cleanup.

## 3. Alert actions

Allow an alert to carry one optional action label and authorized URL, giving users a direct path to resolve the reported issue.
