# Ideas

Only small, additive features are listed here. Refactors and package-wide redesigns are intentionally excluded.

## 1. Server-side timeline filters

Add filters for event, actor, relation, and date range so long activity histories can be narrowed before records are loaded.

## 2. Version comparison

Let users select two activity entries and display their changed attributes side by side as a field-level diff.

## 3. Audit export

Export the authorized activity history for one record to CSV or JSON while honoring the same visibility and tenant constraints as the timeline.
