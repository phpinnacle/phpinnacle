# Ideas

Only small, additive features are listed here. Refactors and package-wide redesigns are intentionally excluded.

## 1. Application palette presets

Allow applications to register named color groups so a picker can offer approved brand and semantic swatches alongside free color selection.

## 2. Contrast guidance

Calculate WCAG contrast against a configured background, recommend a readable foreground, and optionally warn when a selected color misses the requested threshold.

## 3. Recent colors

Keep a browser-local list of recently selected colors for quick reuse across color fields.
