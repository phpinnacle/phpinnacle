# Ideas

Only small, additive features are listed here. Refactors and package-wide redesigns are intentionally excluded.

## 1. User invitations

Complete the existing invitation model with issue, resend, revoke, expiry, and acceptance flows, including assignment of the intended roles after registration.

## 2. Personal access token management

Provide a self-service page for creating named Sanctum tokens with abilities and expiry, showing each secret once, and revoking existing tokens.

## 3. Active session management

Show a user's active sessions with device, IP address, and last activity, and allow them to revoke other sessions after password confirmation.
